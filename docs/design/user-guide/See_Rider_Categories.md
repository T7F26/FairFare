See Rider Categories

Who uses this screen: Admin
Where to find it: FairFare Admin → Rider Categories button at the top of the page

What this screen is for

The Rider Categories screen shows every rider category in FairFare with its discount at each transit agency and the proof a rider needs for that category. Use it to check that the discounts are still correct and to spot rules that are out of date.

How to use it
Open the FairFare Admin site.
Click Rider Categories at the top of the page.
The table loads with one row for each rider category:
Adult
Youth
Student
Post-Secondary Student
Senior
Low-Income
Read across a row to see that category's discount at each agency: TTC, GO Transit, MiWay, Brampton Transit, YRT and Durham Region Transit.
Look at the Proof Required column to see what a rider must show to use that category (for example, a government photo ID showing age 65+ for Senior).
Reading the table
What you see	What it means
A percentage (for example 40%)	The category's fare is that much cheaper than the adult fare at that agency.
100%	The category rides free at that agency (for example, seniors on MiWay).
A dash (-)	The agency has no discount for that category, so the rider pays the adult fare.
None in Proof Required	No proof is needed (Adult).
If something goes wrong

If you see "Could not load rider categories. Try again.", FairFare could not get the rider category data. Refresh the page after a minute. If the message is still there, tell the development team.

Notes
This screen is read-only. Editing a discount and adding a new rider category will be added in later stories (Edit Discount and Add Rider Category).
Discounts are based on each agency's 2026 PRESTO fares compared with the adult fare.
